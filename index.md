## 🚀 Getting Started
Welcome to the agent-creds project! This application focuses on providing ephemeral credentials for agents, using macaroons and Envoy as a transparent proxy. It helps you secure your agent communications without the hassle.

## 📋 System Requirements
- **Operating System:** macOS 10.14 or later
- **Memory:** Minimum 4 GB RAM
- **Disk Space:** At least 100 MB of free space

## 🔍 Features
- **Ephemeral Credentials:** Automatically generate temporary credentials for agent sessions.
- **Macaroons Support:** Use macaroons to manage access rights effectively.
- **Envoy Integration:** Leverage Envoy as a proxy to enhance security without additional setup.
